# AML More Butterflies

Advanced Machine Learning Project

## Overview

This project investigates the use of targeted generative data augmentation to improve butterfly species classification under severe class imbalance conditions.

The proposed pipeline identifies the weakest-performing butterfly classes and selectively enriches them using synthetic samples generated by:

* Conditional Variational Autoencoder (cVAE)
* Conditional Generative Adversarial Network (cGAN)

To improve sample reliability, a confidence-based Top-K filtering strategy is applied before integrating generated images into the training dataset.

## Dataset

The project uses a butterfly image dataset containing 75 distinct species.

The dataset is divided into:

* Training Set
* Validation Set
* Test Set

Weak classes are identified through an initial baseline classification analysis.

## Methodology

### Baseline Classifier

A Convolutional Neural Network (CNN) is first trained on the original dataset to identify weak classes.

### Traditional Augmentation

Standard geometric transformations are applied:

* Random Horizontal Flip
* Random Rotation
* Random Affine Transformations
* Color Jitter

### Conditional Variational Autoencoder (cVAE)

A class-conditioned VAE is trained to generate synthetic butterfly images for minority classes.

### Conditional Generative Adversarial Network (cGAN)

A class-conditioned GAN is trained to generate realistic butterfly images from latent noise vectors.

### Top-K Filtering

Generated samples are evaluated using the baseline classifier.

For each weak class:

1. Confidence scores are computed.
2. Samples are ranked.
3. Only the Top-K highest-confidence images are retained.
4. Selected samples are incorporated into the augmented training set.

## Results

| Model                   | Accuracy | Macro F1 |
| ----------------------- | -------: | -------: |
| Baseline CNN            |    45.0% |    0.418 |
| Baseline + Augmentation |    50.5% |    0.460 |
| Hybrid + cVAE           |    63.8% |    0.618 |
| Hybrid + cGAN           |    58.3% |    0.559 |

The cVAE achieved the best overall classification performance.
